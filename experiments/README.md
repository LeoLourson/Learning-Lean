# Опыты

Класс `experiment`: вычислительная или символьная проверка гипотезы, которую
нельзя закрыть рассуждением. Один опыт — одна папка `E<номер>/` с
`README.md` (шапка и вывод), кодом запуска и сохранёнными данными.

```yaml
---
id: E1
title: Численная проверка отделённости собственных значений
node: I12
status: done
---
```

Опыты: E1 (I22, `done`), E2 (I26, `done`: ВКБ-квазимоды и $\kappa_k$ для $a=x+1/2$), E3 (I28, `done`: число собственных значений в окне ширины $1+3W$ выходит на плато 160 и 475 до $n=900$).

- `node` — идентификатор идеи (`I…`) или записи (`C…`), которую опыт проверяет.
- `status`: `open` | `done` | `failed`.
- Номер — следующий по порядку, только дописывается; опыт не удаляется даже при
  отрицательном результате: отрицательный результат закрывает идею, а не папку.

Опыт ставит роль `experimenter`; её отчёт — данные, статус ставит вызывающая
сторона. Результат, вошедший в доказательство, переносится в запись `claims/C*.md`
ссылкой на номер опыта.

Расчёты до 12.10.2026 лежат в `output/ideas/` — это цех, а не класс; при
необходимости переносите их сюда с новым номером.
