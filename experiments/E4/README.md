# E4. Идея I32: формула $\Delta(\mu)$ при постоянном $a=c$

Запуск: `uv run experiments/E4/run.py` (на Windows с `PYTHONUTF8=1`).

## Вопрос и исход, опровергающий гипотезу (записано до расчёта)

Гипотеза: нули выписанной в I32 функции

$$
\Delta=-2\alpha_1\alpha_2C_+S_--2\beta_1\beta_2\mu^2\rho_+\rho_-S_+C_-+\mu(\alpha_1\beta_2-\alpha_2\beta_1)(\rho_+S_+S_--\rho_-C_+C_-),
$$

$\rho_\pm=\ell_\pm=(1\pm c)^{-1/2}$, $\lambda=\mu^2$, совпадают со спектром
$L_cy=-y''(x)-cy''(-x)$ на $(-1,1)$ с условиями $\alpha_1y(-1)+\beta_1y'(-1)=0$,
$\alpha_2y(1)+\beta_2y'(1)=0$ при $c=1/2$ и $c=-1/2$. Первый расчёт: $y(-1)+y'(-1)=0$,
$y'(1)=0$, то есть $(\alpha_1,\beta_1,\alpha_2,\beta_2)=(1,1,0,1)$.
Опровергает: расхождение первых 30 чисел $\mu_k$ больше $10^{-8}$ либо несовпадение числа
вещественных и невещественных $\lambda$. Для $c=-1/2$ проверяются два варианта: формула как
записана и с обменом $\ell_+\leftrightarrow\ell_-$, $\rho_+\leftrightarrow\rho_-$ в $\Delta$.

Метод 1: коллокация Чебышёва–Лобатто (обобщённая задача, строки условий заменяют краевые
строки), $N=60,90,120$. Метод 2: конечные разности второго порядка (сетка с узлами $\pm1$,
условия односторонними разностями второго порядка), $n=2000,4000$ с экстраполяцией Ричардсона.
Корни $\Delta$ — `brentq`, допуск $10^{-14}$.

## Проверка метода

Ожидалось и получено (коллокация $N=120$, `run.log`):

- $c=0$, Дирихле–Нейман ($y(-1)=0$, $y'(1)=0$): $\mu_k=\pi(k+1/2)/2$; расхождение $2.7\cdot10^{-11}$ по первым 30.
- $c=0$, условия $(1,1,0,1)$: независимый скалярный определитель $\mu\cos2\mu+\mu^2\sin2\mu=0$ (решение $A\cos\mu(x+1)+B\sin\mu(x+1)$); расхождение с коллокацией $4.5\cdot10^{-11}$, с нулями $\Delta$ при $c=0$ $6.8\cdot10^{-14}$. Конечные разности: $4.3\cdot10^{-3}$ ($n=2000$), $1.1\cdot10^{-3}$ ($n=4000$), порядок 2.
- При $N=60$ верхние моды из тридцати не разрешены (расхождение с $N=120$ порядка $0.1$), поэтому основной расчёт берёт $N=120$.

## Дополнение: случаи 1 и 2 формулы (A)

Классификация (A) идёт по $\beta_j$: случай 1 — $\beta_1\beta_2\ne0$, случай 2 — $\beta_1=\beta_2=0$,
случай 3 — ровно одно $\beta_j=0$. Условия $y(-1)+y'(-1)=0$, $y'(1)=0$ имеют $\beta_1=\beta_2=1$,
то есть относятся к **случаю 1**, а не к случаю 3; обнуление $\alpha_2$ случай не меняет. Запись
«случай 3» в предыдущей версии этого отчёта и в критике I32 после E4 неверна. Случай 3 при $c\ne0$
не проверен.

Вопрос и исход (записаны до прогона): нули $\Delta$ из (A) при $c=\pm1/2$ совпадают с коллокацией
по первым 30 значениям $\mu_k$; опровержение — расхождение больше $10^{-8}$. Наборы выбраны до
расчёта: случай 1 — $(1,1,0,1)$, $(2,1,-1,3)$, $(1,-2,3,1)$ (разные знаки, $\alpha_2\ne0$,

## Оценка погрешности

- Коллокация: разность $N=90$ и $N=120$ не больше $4.9\cdot10^{-10}$ во всех восьми прогонах; разность $N=60$ и $120$ велика (до $0.46$) из-за неразрешённых верхних мод. Погрешность $\mu_k$ порядка $10^{-10}$.
- Расхождение $\Delta$ с коллокацией не больше $4.7\cdot10^{-10}$, в 20 раз ниже порога $10^{-8}$ и того же порядка, что разность $N=90$ и $120$, то есть определяется коллокацией.
- Конечные разности после Ричардсона (порядок 2) согласуются с коллокацией на $10^{-5}$ (случай 1) и $10^{-7}$ (Дирихле); они независимы от коллокации, но различают варианты лишь на уровне $10^{-5}$. Вариант с обменом ими исключён (расхождение $1.1$ для коллокации).
- Невещественных $\lambda$ с $\lvert\lambda\rvert<10^3$ нет. Нулей $\Delta$ с $\mu>0$ до $\mu\approx45$ не меньше 31; первые 30 сопоставлены по номеру, отрицательное $\lambda$ совпадает с нулём $\Delta(it)$ в шести знаках.
- Невязки собственных пар и обусловленность базиса не вычислялись (задача не самосопряжена, спектр вещественный); значения устойчивы при $N=90\to120$ до $10^{-10}$.

Время расчёта 8.0 с (весь `run.py`).

## Вывод

Формула $\Delta$ из I32 в записи $\rho_\pm=\ell_\pm=(1\pm c)^{-1/2}$ согласуется с гипотезой при
$c=\pm1/2$ в случае 1 (три набора коэффициентов, включая $y(-1)+y'(-1)=0$, $y'(1)=0$) и в случае 2
(Дирихле): расхождение по первым 30 нулям не больше $4.7\cdot10^{-10}$, порог $10^{-8}$ не нарушен.
Обмен $\ell_+\leftrightarrow\ell_-$, $\rho_+\leftrightarrow\rho_-$ в записи через $(1\pm c)$ не согласуется
со спектром ни при одном знаке $c$ (расхождение $\sim1$); запись через $\ell_\pm=(1\pm\lvert c\rvert)^{-1/2}$
при $c<0$ даёт ту же функцию, что и обмен в записи через $(1\pm c)$.

## Не проверено

Переменный $a$ (остаток $O(\mu^{-1})$, шаг 2 I32); случай 3 формулы (A) при $c\ne0$ (ровно одно
$\beta_j=0$, например $y(-1)=0$, $y'(1)=0$, то есть набор $(1,0,0,1)$; добавляется одной строкой в словарь `cases` в `run.py`); $c$ вне $\pm1/2$;
невещественные $\mu$ в большом числе; базисность (C).
