# E7. Идея I36, случай (B)

Запуск: `uv run experiments/E7/run.py` (лог — `run.log`).

## Вопрос и исход, опровергающий гипотезу (записано до расчёта)

Задача: $L_ay=-y''(x)-a(x)y''(-x)$ на $(-1,1)$ с условиями $y(1)=c\,y(-1)$, $y'(1)=c\,y'(-1)$,
$c=\pm1$, $a=1/2+x/4$ ($a(1)=3/4\ne a(-1)=1/4$). Вопрос: ограничены ли при росте номера
число обусловленности матрицы Грама нормированных собственных функций внутри групп
ограниченной длины по $\sqrt\lambda$ и норма $L_2$-проекторов Рисса на эти группы?

Идея I36 называет (B) препятствием схемы, а не утверждением об отсутствии базиса. Поэтому
исходы такие. Неограниченный рост (при любом выборе границ окон длины $W$ из
проверяемого набора) согласуется с тем, что (B) — содержательное препятствие. Ограниченность
согласуется с тем, что нужен другой сплетающий оператор. Контроли: $a=1/2$ (периодические и
антипериодические условия; спектр известен точно, базис ортонормированный: нормы проекторов
равны 1, Грам единичная); сравнение: $a=1/2+x^2/4$ ($a(1)=a(-1)$, идея обещает базис со
скобками) и Дирихле для $a=1/2+x/4$ (базис Рисса, C-записи проекта).
