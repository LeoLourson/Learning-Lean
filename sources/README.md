# Опись коллекции источников

Класс — `collection` (`sources/registry.json` и `sources/README.md`; таблица классов —
`LAYOUT.md`). Здесь опись чужих текстов: что собрано, откуда взято и чем связано с
проектом. Формулировки чужих теорем и наших утверждений о них — в карточках.

- **Реестр** — [registry.json](registry.json): 47 записей S1…S47 с метаданными, версией,
  ссылками, ролью в проекте, контрольными суммами и именами локальных файлов. Реестр правит
  только `python tools/sources/lit.py` (`add`, `add-file`, `attach`, `fetch`, `pdf`);
  вручную файл не правят.
- **Каталог** — `sources/catalog.md` — производный: собирается
  `python tools/sources/lit.py catalog` из реестра, вручную не правится. В нём ссылки,
  статусы и SHA-256 по каждой записи. SHA-256 относится к локальному файлу; `eprint_sha256` —
  сумма скачанного с arXiv архива `e-print`, а не собранного из него `.tex`, поэтому с
  локальным LaTeX она не совпадает.
- **Карточки проверенных теорем** — класс `card`, файлы `claims/S*.md`. Карточка — наше
  утверждение о чужом результате, поэтому она лежит среди наших утверждений, а не в
  `sources/`; карточку по страницам PDF сверяет агент `source-verifier`. Наличие полного
  текста не означает проверку его теорем.
- **Полные тексты и поисковый индекс** — `output/literature/`, вне Git.

## Как пополняется

1. Кандидатов даёт `find` (zbMATH, arXiv, журналы MathNet) и списки цитирования `cites`.
2. `add` принимает идентификатор arXiv (`2107.12209`), MathNet (`mathnet:rm9740`) или DOI
   (`10.1070/RM9740`): с arXiv приходит авторский LaTeX, с MathNet — PDF, по одному DOI —
   только описание. Источник без arXiv, MathNet и DOI добавляет `add-file`; файл,
   полученный по подписке или от автора, прикрепляет `attach`.
3. `catalog` пересобирает каталог, `index` — поисковый индекс. Роль источника
   (`--role`) пишется по-русски в одну-две фразы: какой метод или результат и чем
   постановка отличается от нашей.
4. Карточку теоремы заводит не опись: карточка — класс `card` в `claims/S*.md`, её
   создаёт агент вершины `claims`, а сверяет `source-verifier`.

## Инструмент

Всё делает `python tools/sources/lit.py КОМАНДА`. Часть команд повторена инструментами
MCP-сервера `lit` из `.mcp.json`; поверхность MCP уже командной строки: три команды
доступны только из CLI.

| Команда CLI | Действие | В MCP |
| --- | --- | --- |
| `find "запрос" [--in ОТКУДА]` | кандидаты с аннотациями; `--in` — zbMATH, arXiv или журналы MathNet; без него — zbMATH и arXiv | `find` |
| `cites S2 [--refs]` | кто цитирует источник или его список литературы | `cites` |
| `add 2107.12209 mathnet:rm9740 10.1070/RM9740 --role "…"` | добавить работы: метаданные, текст, каталог, индекс | `add` |
| `add-file ПУТЬ_ИЛИ_ССЫЛКА --title … --authors … --version … --url … --name … --role …` | источник без arXiv, MathNet и DOI | только CLI |
| `attach S31 ПУТЬ_ИЛИ_ССЫЛКА` | прикрепить PDF или LaTeX, полученный вручную | `attach` |
| `fetch [КОД…]` | восстановить недостающие файлы реестра | `fetch` |
| `pdf S22` | скачать PDF: по нему сверяются номер теоремы и страница | `pdf` |
| `pages S22 [--range 3-10]` | страницы PDF в PNG и их текстовый слой | `pages` |
| `tex S22 [--build]` | собрать транскрипцию из частей и записать её как LaTeX источника | `tex` |
| `catalog` | пересобрать `sources/catalog.md` | только CLI |
| `index [КОД…]` | проиндексировать новые и изменившиеся тексты | только CLI |
| `search "запрос" [-k 8] [--code S4] [--kind theorem]` | поиск по полным текстам | `search` |
| `show 1234 [-n 1]` | кусок целиком по номеру из поиска, с соседями | `show` |
| `list` | источники реестра и число кусков в индексе | `papers` |

Остальные действия CLI (`-h`, разбор ключей, сообщения об ошибках) есть только в
командной строке; MCP-сервер возвращает ошибку текстом, не обрывая сессию. Поиск в
MCP считает модель в памяти процесса, в CLI — при каждом запуске.

### Откуда берётся текст

- **arXiv.** Скачивается авторский исходник: главный файл с подставленными `\input` и
  списком литературы сохраняется как `output/literature/ИДЕНТИФИКАТОР.tex`. Номеров
  теорем и страниц в исходнике нет, для карточки нужен PDF (`pdf КОД`).
- **MathNet.** По идентификатору статьи (`mathnet:rm9740`, ссылка или DOI `10.4213/…`)
  берутся метаданные со страницы статьи и PDF. Исходников на сайте нет: LaTeX делает
  команда `/transcribe`. Через VPN-туннель сайт не отвечает, а ссылка на PDF работает
  только с cookie сессии. Скрипт держит сессию сам, а `mathnet.ru` запрашивает с адреса
  сетевого интерфейса вне туннеля; список таких хостов задаёт переменная
  `LIT_DIRECT_HOSTS`. PDF обзора S3 восстанавливается с MathNet.
- **DOI.** Берётся только описание из Crossref. Файл, полученный по подписке или от
  автора, прикрепляется командой `attach`.
- **Транскрипция.** `/transcribe` читает страницы PDF и пишет LaTeX по частям в
  `output/literature/parts/`; `tex КОД` собирает их, проверяет окружения, скобки и метки
  страниц и вносит файл в реестр. В тексте стоят `\pagemark{N}` с печатными номерами
  страниц и `\begin{statement}{Теорема}{6.6}` с печатными номерами утверждений, поэтому
  поиск показывает и то и другое. Транскрипцию делает модель: при расхождении первичен
  PDF, а место, прочитанное неуверенно, помечено `\unsure{…}`. LaTeX обзора S3 распознан
  по PDF сторонним средством и считается транскрипцией.

### Поиск

Поиск гибридный: BM25 по словам и близость векторов модели
`intfloat/multilingual-e5-small`, ранги складываются. Запрос пишется по-русски или
по-английски, формулы — в LaTeX. LaTeX режется на окружения теорем, определений и
доказательств и на абзацы разделов; текстовый слой PDF — по страницам. В выдаче указаны
файл и строка, у транскрипции — печатная страница, у текста PDF — страница файла. Индекс
`output/literature/index/lit.sqlite` обновляется при добавлении источника и перед каждым
поиском. Модель считает на процессоре через ONNX Runtime; запрос занимает около 2 с. При
первом запуске модель загружается из Hugging Face (около 0,5 ГБ). Нужны пакеты
`onnxruntime`, `tokenizers`, `huggingface_hub`, `numpy`, `certifi`, для PDF — `PyMuPDF`,
для сервера — `mcp` версии 1.

Новых кандидатов лучше всего даёт zbMATH (`find` без `--in`): в нём есть переводные
журналы и аннотации; в arXiv работ по теме почти нет. Работы с MathNet находятся через
`find --in mathnet` по русскому названию и через списки цитирования `cites`.

Найденный кусок — непроверенный источник. Теорема становится посылкой после карточки в
`claims/S*.md`; карточку по страницам PDF сверяет агент `source-verifier`. Новые источники
ищет команда `/sources`.
