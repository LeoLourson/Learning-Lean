# Источники

В подборке 21 полная статья: 20 получены к 09.10.2026, обзор S3 добавлен 10.10.2026 из
локального архива. Реестр — [catalog.md](catalog.md), машиночитаемая версия с SHA-256 —
[papers.json](papers.json), карточки проверенных теорем — [results.md](results.md).
PDF и извлечённые тексты лежат в `output/literature/`.

- `python sources/build_catalog.py` проверяет через PyMuPDF формат каждого PDF, число
  страниц и извлечение текста и пересобирает `catalog.md` и `papers.json`.
- `scripts/download-literature.ps1` восстанавливает PDF по ссылкам из `papers.json` и
  сверяет контрольные суммы. S3 по ссылке не загружается, его PDF берётся из локального
  архива.

В доказательствах проекта используются S4 (C6, C7, C16), S3 (C6), S2 (C3), S1 (C1) и
схема S5 (C13); применимость каждой теоремы проверена в `context.md` и `results.md`.
Остальные статьи — контекст по методам, их теоремы посылками не служат.
