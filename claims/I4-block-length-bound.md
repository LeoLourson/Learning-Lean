- Дата: 11.10.2026. Статус: цель исследования.
- Наблюдение: в C13–C15 блоки берутся из `exists_sparse_cuts`. Его формулировка даёт
  разрезы $\xi_k$ с $2\xi_k\le\xi_{k+1}$ и зазором $1/(4c_2)$ вокруг каждого разреза,
  где $c_2$ — постоянная из оценки $N(t)\le c_2t+C_0$ для числа $N(t)$ индексов $i$ с
  $\omega_i\le t$. Разрезы растут не медленнее геометрической прогрессии, поэтому для
  числа собственных значений в блоке $k$ есть только оценка $c_2\xi_{k+1}+C_0$, растущая
  с $k$; ограниченность размерностей блоков не доказана.
- Где используется удвоение (проверено 11.10.2026): поле `ξ_double` структуры
  `SpectralBlocks` в `Involution/Model/BlockMultiplier.lean` входит в `ξ_pow` и `block_gap`. Мультипликатор
  между блоками $k$ и $k+n+1$ оценивается через $2^{-n}/\delta$, и сумма по $n$ сходится
  как геометрическая прогрессия. При разрезах с шагом $h$ та же оценка даёт
  $1/(nh)$, и сумма по $n$ расходится логарифмически.
- Вывод: арифметический шаг несовместим с суммированием норм по диагоналям блочной
  матрицы. Нужна оценка всего мультипликатора $1/(\omega_i-\omega_l)$ сразу, типа
  неравенства Гильберта, либо понижение порядка возмущения до $0$ (I6), при котором
  блоки определяются асимптотикой, а не разрезами.
