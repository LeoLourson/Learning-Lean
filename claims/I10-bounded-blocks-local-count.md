- Формулировка. В условиях C16 существует $m$, для которого блоки базиса со скобками
  можно выбрать размерности не больше $m$.
- Набросок. По замечанию 6.7 достаточно локальной оценки
  $R(t)=n(t+bt^{1/2})-n(t-bt^{1/2})=O(1)$ для собственных значений $L_b$. Они
  распадаются на две серии задач $-(1\pm b)f''=\lambda f$ на $(0,1)$. При
  $b\in W^2_\infty$ преобразование Лиувилля приводит каждую к $-u''+qu=\lambda u$ с
  $q\in L_\infty$ на отрезке длины $S_\pm=\int_0^1(1\pm b)^{-1/2}dx$, откуда
  $\bigl\lvert\lambda_n^\pm-(\pi(n-\theta_\pm)/S_\pm)^2\bigr\rvert\le\lVert q\rVert_\infty$,
  $\theta_+=1/2$, $\theta_-=0$. Тогда $\sqrt{\lambda_n^\pm}=\pi(n-\theta_\pm)/S_\pm+O(1/n)$,
  и окно $\lvert\lambda-t\rvert\le bt^{1/2}$ содержит не больше
  $2(bS_\pm/\pi+1)$ значений каждой серии.
- В Lean: в `MMWindow` окна с ограниченным числом частот находятся по принципу Дирихле;
  при локальной оценке годится каждое окно, и разрезы можно ставить с ограниченным шагом.
- Проверка: при постоянном $b=c$ серии равны $(1+c)(n+\tfrac12)^2\pi^2$ и
  $(1-c)m^2\pi^2$ (C3), оценка выполнена с $q=0$.
