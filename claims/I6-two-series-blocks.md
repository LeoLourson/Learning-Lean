- Дата: 11.10.2026. Статус: цель исследования; асимптотика подтверждена численно, не
  доказана.
- Формулировка. Пусть $a\in W^2_\infty$ вещественна, $0<m\le\lvert a\rvert\le M$,
  $\lvert a(x)a(-x)\rvert\le\kappa<1$, и $b=\sigma\sqrt{a(x)a(-x)}$ — чётный коэффициент
  из C10. Обозначим через $\mu_n(a)$ и $\mu_n(b)$ квадратные корни из собственных
  значений $L_a$ и $L_b$, упорядоченные по модулю. Гипотеза:
  $\mu_n(a)-\mu_n(b)=O(1/n)$, и корневые подпространства $L_a$ объединяются в инвариантные
  блоки размерности не выше $2$, образующие базис Рисса подпространств.
- Набросок. По C10 $L_a$ подобен $L_b+T_bB_0$, $B_0f=-2\varphi f'-wr''f$,
  $\varphi=r'/r=a'/(2a)$. Оператор $L_b$ распадается по чётности на
  $(1+b)(-D^2)$ и $(1-b)(-D^2)$ (C5). Нечётная часть $\varphi$ сохраняет чётность $f$,
  чётная часть $\varphi_e=\tfrac14\bigl(a'(x)/a(x)+a'(-x)/a(-x)\bigr)$ её меняет.
  Шаг 1: диагональные элементы $\langle\varphi_of_n',f_n\rangle$ ограничены, так как
  $f_n'f_n=(f_n^2)'/2$; сдвиг $\lambda_n$ равен $O(1)$, сдвиг $\mu_n$ — $O(1/n)$.
  Шаг 2: элементы $\langle\varphi_ee_n',o_m\rangle$ между сериями при близких $\lambda$
  не имеют стационарной фазы, поскольку $1+b\ne1-b$; после интегрирования по частям они
  равны $O(1)$. Шаг 3: преобразование подобия $I+X$, где $X$ решает
  $[L_b,X]=$ нерезонансная часть возмущения, оставляет возмущение порядка $0$. Шаг 4:
  в окне длины $\delta$ по $\mu$ каждая серия даёт не больше одного значения, откуда
  размерность блока не выше $2$.
- Проверка (`output/ideas/split_check.py`, коллокация Чебышёва, $N=200$, первые 60
  значений для $a=1/2+x/4$): $n\lvert\mu_n(a)-\mu_n(b)\rvert\le0.18$; нормы спектральных
  проекторов лежат в $[1.047,1.540]$ (пересчёт `split_check.py` 13.10.2026, см. критику I20); при $n=25,26$ значения
  $\mu=36.2849\pm0.016i$ комплексно сопряжены. Вблизи сближения серий собственные
  значения $L_a$ сходят с вещественной оси, поэтому обычный базис Рисса из собственных
  функций для C6 может отсутствовать: в модели $2\times2$ с расстройкой $\delta_n$ и
  связью $\varepsilon_n\sim c/n$ норма проектора не ограничена при
  $\delta_n\approx2\varepsilon_n$. Доказательства этого нет.
