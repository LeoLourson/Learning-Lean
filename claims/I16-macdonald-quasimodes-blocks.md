- Где новое по сравнению с I7, I9, I12, I13. I7 исключает базис из собственных функций:
  его квазимода имеет невязку $O(1)$, а шаг 2 (`rieszEigenbasis_lower_bound`) использует
  одномерность блоков. Для блока размерности $d\ge2$ расстояние до спектра резольвенту
  не оценивает, и довод I7 не переносится. Здесь два новых хода: (i) точное решение
  $u_t=s^{1/2}K_1(4ts^{1/2})$ вместо ВКБ-приближения I7, что даёт экспоненциально малую
  невязку; (ii) оценка резольвенты конечномерного блока через определитель,
  $\lVert M^{-1}\rVert\le\lVert M\rVert^{d-1}/\lvert\det M\rvert$, которая при
  ограниченном $d$ даёт степенной рост по $\lvert z\rvert$. I12 и I13 искали
  ограниченные скобки для знакопостоянного $a$ через отделённость номеров и условие
  Шура; здесь узел другой, отделённость собственных значений и асимптотика спектра не
  используются, нужна только плотность (счётная функция), а вывод отрицательный.
- Формулировка. Пусть $a(x)=x/2$, $K_a=L_a^{-1}$ (C8, C17). Не существует семейства
  подпространств $\lbrace N_k\rbrace_{k\ge1}$ пространства $L_2(-1,1)$ со свойствами:
  (а) $\dim N_k\le d<\infty$ при всех $k$, $N_k\subset D(L_a)$, $L_aN_k\subset N_k$;
  (б) $\lbrace N_k\rbrace$ — базис Рисса из подпространств: есть ограниченный обратимый
  $B$, для которого $BN_k$ попарно ортогональны и их сумма плотна.
  Способ группировки собственных значений по блокам произволен, порядок по модулю не
  предполагается. Следствия: (1) нет базиса Рисса со скобками, в котором число корневых
  функций в скобке ограничено; (2) если алгебраические кратности собственных значений
  $L_a$ ограничены в совокупности, то нет базиса Рисса из собственных и присоединённых
  функций. О скобках неограниченной длины идея ничего не утверждает.
- Набросок.
  Шаг 1, точное решение. Пусть $s=1+ix/2$, $t>0$, $u_t=s^{1/2}K_1(4ts^{1/2})$, где $K_1$ —
  функция Макдональда, ветвь корня главная. Тогда $s\cdot(-u_t'')=t^2u_t$ на $(-1,1)$ и
  $u_t'=-itK_0(4ts^{1/2})$. Вывод: при $u(x)=f(\zeta)$, $\zeta=s(x)$, имеем
  $u''=-f''/4$, и уравнение переходит в $\zeta f''=4t^2f$ с решениями
  $\zeta^{1/2}K_1(4t\zeta^{1/2})$, $\zeta^{1/2}I_1(4t\zeta^{1/2})$
  [стандартно: уравнение Бесселя, DLMF 10.13; в реестре источника нет]. Невязка I7
  $-3u/(64s)$ — второй член разложения $K_1$.
  Шаг 2, квазимода. Пусть $\chi$ гладкая, $\chi=1$ на $[-1/2,1/2]$, $\chi=0$ вне
  $(-3/4,3/4)$, $Z_t=\chi u_t$, $y_t=U^{-1}Z_t$. Тогда $y_t\in D(L_a)$ и по C4
  $(L_a-t^2)y_t=U^{-1}\bigl(-s(\chi''u_t+2\chi'u_t')\bigr)$ [C4,
  `oddCoefficient_unitary_multiplication`]. Нужна оценка

  $$
  \lVert(L_a-t^2)y_t\rVert\le C_1e^{-ct}\lVert y_t\rVert,\qquad t\ge1,\tag{1}
  $$

  с $c>0$. Она следует из $\lvert K_\nu(w)\rvert\asymp\lvert w\rvert^{-1/2}e^{-\operatorname{Re}w}$
  равномерно при $\lvert\arg w\rvert\le1/4$, $\lvert w\rvert\ge1$, $\nu=0,1$, и из того, что
  $\operatorname{Re}s^{1/2}$ строго возрастает по $\lvert x\rvert$
  ($\operatorname{Re}\sqrt{1+i/4}-1=0{,}0077$): ожидается $c$ чуть меньше $0{,}031$
  [пробел: двусторонняя оценка $K_0$, $K_1$ в секторе с явными постоянными; DLMF 10.40.2,
  10.40.10 или интеграл $K_\nu(w)=\int_0^\infty e^{-w\cosh\theta}\cosh(\nu\theta)d\theta$].
  Для шага 7 хватит убывания быстрее каждой степени $t$.
  Шаг 3, счёт. Собственных значений $L_a$ с $\lvert\lambda\rvert\le R$, считая
  алгебраическую кратность, не больше $c_0\sqrt R$, $c_0=2e/\pi$: по C4
  $s_j(K_a)\le s_j(G)=4/(\pi j)^2$, а по неравенству Вейля
  $\lvert\mu_n\rvert^n\le\prod_{j\le n}s_j$ [стандартно: неравенство Вейля для
  собственных и сингулярных чисел компактного оператора; C17, оценка
  $\lVert T_a^{-1}\rVert\le1$ при $\alpha=0$]. Базис для этого шага не нужен, в отличие
  от шага 3 в I7.
  Шаг 4, выбор точки. При $r\ge r_0$ на отрезке $[r,2r]$ найдётся $z$ с
  $\lvert z-\lambda\rvert\ge r^{1/4}$ для всех собственных значений $\lambda$: значения с
  $\lvert\lambda\rvert>4r$ удалены на $2r$, остальных не больше $2c_0\sqrt r$, и
  исключённые интервалы имеют суммарную длину не больше $4c_0r^{3/4}<r$ [шаг 3].
  Зазор между собственными значениями не используется (ловушка I12 не задета).
  Шаг 5, блок. Пусть $N$ — инвариантное подпространство, $\dim N\le d$,
  $K_N$ — сужение $K_a$ на $N$, $M=I-zK_N$. Тогда $\det M=\prod_j(1-z/\lambda_j)$ по
  собственным значениям блока; при $\lvert\lambda_j\rvert\le4r$ множитель по модулю не
  меньше $r^{-3/4}/4$, при $\lvert\lambda_j\rvert>4r$ — не меньше $1/2$. Отсюда

  $$
  \lVert(I-zK_N)^{-1}\rVert\le\frac{\lVert M\rVert^{d-1}}{\lvert\det M\rvert}
  \le\bigl(1+2r\lVert K_a\rVert\bigr)^{d-1}\bigl(4r^{3/4}\bigr)^{d}=:B_r
  $$

  [стандартно: для обратимой матрицы порядка $d$
  $\lVert M^{-1}\rVert=1/\sigma_d$ и $\lvert\det M\rvert\le\sigma_1^{d-1}\sigma_d$].
  Используется $\lVert K_N\rVert\le\lVert K_a\rVert$; нормы сужения $L_a$ на $N$ и
  расстояния между собственными значениями не нужны.
  Шаг 6, сборка. Пусть (а), (б) выполнены, $y\in D(L_a)$, $h=(L_a-z)y$. Тогда
  $(I-zK_a)y=K_ah$. Ограниченный $K_a$ сохраняет каждое $N_k$ и потому коммутирует с
  координатными проекторами $Q_k$; значит, $(I-zK_{N_k})y_k=K_ah_k$ для $y_k=Q_ky$,
  $h_k=Q_kh$. По (б) $m\lVert y\rVert^2\le\sum\lVert y_k\rVert^2\le M_0\lVert y\rVert^2$,
  откуда $\lVert y\rVert\le(M_0/m)^{1/2}B_r\lVert K_a\rVert\lVert h\rVert$
  [шаг 5; стандартно: базис Рисса из подпространств; определения — S3, § 6, карточки
  нет]. Действие неограниченного $L_a$ на ряд $\sum y_k$ нигде не используется.
  Шаг 7, противоречие. При $y=y_t$, $t^2=z\in[r,2r]$ из (1) получаем
  $1\le(M_0/m)^{1/2}\lVert K_a\rVert C_1B_re^{-c\sqrt r}$, а $B_r\le C_2r^{7d/4-1}$
  [шаги 2, 4, 6]. При больших $r$ неравенство неверно.
  Шаг 8, следствие (2). Базис Рисса из корневых функций после объединения векторов с
  одним собственным значением даёт базис Рисса из корневых подпространств; их
  размерности равны алгебраическим кратностям [стандартно: группировка безусловного
  базиса]. Ограниченность кратностей для $a=x/2$ не обоснована [пробел]; численно первые
  40 собственных значений просты (I5).
