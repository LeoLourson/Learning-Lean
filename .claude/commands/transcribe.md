description: Транскрипция PDF источника в LaTeX по страницам
---

Переведи PDF источника в LaTeX: $ARGUMENTS

Аргумент — код `S…`, можно с диапазоном страниц файла («S12 5-20»), можно несколько кодов.
Запуск команды — прямой запрос пользователя на запуск ролей.

## 1. Подготовка

1. `python tools/sources/lit.py list`: источник есть в реестре `sources/registry.json`. Если
   у него авторский LaTeX с arXiv, транскрипция не нужна: скажи это и остановись.
2. `python tools/sources/lit.py pages S12` отрисовывает страницы и печатает их число. Нет
   PDF — `python tools/sources/lit.py pdf S12`; для закрытого источника файл прикрепляет
   пользователь командой `attach`.

## 2. Части

Раздели страницы на части по восемь; скан без текстового слоя с плотными формулами — по
пять. Части одного источника идут строго по порядку: каждому следующему вызову передаётся
конец предыдущей части.

Для каждой части запусти роль `latex-transcriber`. В задании: код источника, диапазон
страниц файла, а для всех частей, кроме первой, — последние пятнадцать строк предыдущей
части из отчёта и незакрытое окружение, если оно было. Если в первой части много меток
`\unsure`, отметь в отчёте, что следующие части требуют модели с поддержкой изображений.

Разные источники можно вести параллельно.

## 3. Сборка

`python tools/sources/lit.py tex S12 --build` склеивает части, проверяет окружения, скобки и
метки страниц, собирает PDF и вносит LaTeX в реестр и индекс. Замечания исправляются в
файлах частей по изображениям страниц, после чего команда повторяется. Метки `\unsure`
остаются: их снимает только человек, сверив место с оригиналом.

## 4. Итог

Проверь поиск: `python tools/sources/lit.py search "…" --code S12 --kind theorem` показывает
утверждения с печатными номерами и страницами. Отчёт: источник, число страниц и частей,
число меток `\unsure` и их страницы, замеченные опечатки оригинала, оставшиеся замечания
сборки.

Транскрипцию делает модель. Сверку карточки `claims/S*.md` по PDF она не заменяет.
