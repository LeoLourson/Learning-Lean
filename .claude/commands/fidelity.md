description: Проверка соответствия формулировок Lean утверждениям записей
---

Проверь соответствие формализации: $ARGUMENTS

Аргумент — номер записи `C…`. Без аргумента берутся все записи, у которых заполнен
`lean_theorem`, а в `checked_by` нет проверки соответствия. Запуск команды — прямой запрос
пользователя на запуск ролей.

1. Для каждой записи запусти роль `fidelity-checker` и передай ей только номер записи.
   Одновременно — не больше четырёх.
2. Проверь, что раздел «Соответствие формализации (ГГГГ-ММ-ДД)» записан в тело записи, и
   впиши роль с датой в `checked_by`. Оговорки впиши в абзац «Границы»; при вердикте «не
   соответствует» поступи по шагу 3 команды `/formalize`.
3. Если проверка повторная, сравни новый раздел с прежним. Изменение смысла формулировки
   назови в отчёте отдельно.
4. `python tools/state/build_index.py`, `python tools/check/structure.py`. Отчёт: по строке на
   запись — объявления, вердикт, расхождения.
